## 凭据与存储

百炼、DeepSeek、高德 Web 服务、和风均已配置。服务端凭据只放在被 Git 忽略的环境文件或加密配置中；甲端通过随变账号取得 Bearer 令牌调用后端，不需要第三方 Key。

服务器 `.state/auth.sqlite3` 保存账号、会话摘要；`providers.sqlite3` 保存加密供应商配置；`budgets.sqlite3` 保存调用额度计数。地图、天气缓存为服务进程内缓存。现阶段不引入 PostgreSQL，不提供跨设备计划同步接口；计划的本地保存继续由甲端负责。

备份应覆盖账号、供应商配置、额度数据库及对应 `provider.key`（或独立保管的 `PROVIDER_MASTER_KEY`）。它们不进入 Git。不得把本机 `.state` 或供应商凭据复制进 APK。

## 服务端限制

以下是本机当前配置值，**不是供应商账户额度**。

| 配置 | 当前值 | 用途 |
|---|---:|---|
| `PARSE_LLM_DAILY_MAX` | 200 | 全局每日解析预算 |
| `PARSE_USER_DAILY_MAX` | 50 | 每用户每日解析预算 |
| `DAILY_LLM_CALLS_MAX` | 3000 | 全局模型调用预算 |
| `DAILY_SEARCH_MAX` | 120 | 搜索预算配置；本冲刺 parse 不调用 POI 搜索 |
| `DAILY_GENERATE_MAX` | 10 | 后续生成预算配置；生成流水线本冲刺未实现 |
| `PARSE_TIMEOUT_S` | 20 秒 | 整次解析上限 |
| `PARSE_LLM_TIMEOUT_S` | 10 秒 | 单次解析模型请求上限 |
| `QW_TIMEOUT_S` | 4 秒 | 和风请求上限 |
| `REFRESH_TIMEOUT_S` | 15 秒 | 整次刷新上限 |

解析预算及重试计数有离线回归保护；日预算以服务端 UTC 日期计算。未实现的生成/搜索功能不因存在配置字段而视为已交付。
