## 给甲的复跑方法

在仓库根使用已有 Python 环境。下面的工具不会自动注册账户；`--login` 要求输入已有用户名和密码，密码隐藏输入。

```powershell
.\.venv\Scripts\python.exe scripts/deploy_smoke.py https://你的服务地址 --login --parse-file request.json
```

`request.json` 示例；`now` 改成实际发送时带时区的 ISO 时间。城市和地点按联调地点填写：

```json
{
  "text": "明天上午十点前到中国国家博物馆参观，从天安门出发，步行。",
  "now": "2026-11-28T20:00:00+08:00",
  "city_adcode": "110100"
}
```

已有令牌可通过 `SUIBIAN_SMOKE_TOKEN` 环境变量提供。单独检查本机开发 MOCK 镜像用 `--allow-mock`，输出会明确提示不能视为真实供应商验收。

甲继续接既有 `parse → 保存 → simulate → replan`，用 `refresh` 拉取路线及天气；登录令牌放请求头。注册、登录和令牌过期行为详见 [账号接入](乙_账号与团队凭据联调.md)。服务端本轮没有实现云端计划存储或自动同步。
