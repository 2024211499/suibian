## 服务端启动

本地 PowerShell，在 `G:\temp\suibian\suibian-main\server` 中执行：

```powershell
..\.venv\Scripts\python.exe -m app.admin --username team-admin
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

第一条命令在终端中隐藏输入两次密码。用户名限 3–32 位英文字母、数字或 `_.-`，密码 12–128 字符。初始化不会覆盖已有管理员密码，也不会把普通用户提升为管理员。

`AUTH_REQUIRED` 默认开启。`MOCK=1` 仅返回业务样例；测试真实解析时在本机 `server/.env` 设置 `MOCK=0`。旧 Android 联调如确实尚未接入登录，可以临时使用 `AUTH_REQUIRED=0`；这会开放业务接口，只适用于隔离的开发环境，管理员接口始终要求管理员令牌。

默认监听本机；手机真机联调需监听可访问的局域网地址，甲将 API 地址设置成开发机地址。正式部署使用现有 Caddy HTTPS 入口，不把管理员密码或令牌发往公网明文 HTTP。Docker Compose 已默认传入 `AUTH_REQUIRED=1`，可用 `docker compose exec api python -m app.admin --username team-admin` 初始化管理员。

## 给甲的最小接入契约

以下 URL 都相对于同一服务端根地址。所有请求体为 JSON。

| 方法和路径 | 请求体／请求头 | 成功返回 |
|---|---|---|
| `POST /v1/auth/register` | `{"username":"demo-user","password":"用户自己设置的密码"}` | HTTP 201，登录会话 |
| `POST /v1/auth/login` | 同上 | HTTP 200，登录会话 |
| `GET /v1/auth/me` | Bearer 令牌 | `{"id":"…","username":"demo-user","role":"user"}` |
| `POST /v1/auth/logout` | Bearer 令牌 | HTTP 204，无响应体 |
| 原有业务接口 | 原有 JSON，加 Bearer 令牌 | 原有业务结构 |
| `GET /v1/health`、`GET /v1/version` | 不要求令牌 | 健康信息／版本信息 |

会话结构：

```json
{
  "access_token": "服务器生成的不透明令牌",
  "token_type": "bearer",
  "expires_in": 86400,
  "user": {"id": "服务端用户ID", "username": "demo-user", "role": "user"}
}
```

业务请求头：`Authorization: Bearer <access_token>`。令牌最长有效 24 小时；退出只撤销当前令牌，其他设备会话不受影响。不提供刷新令牌；过期后重新登录。

甲端在应用私有存储保存令牌，不记录密码或令牌到日志。HTTP 401 提示重新登录，403 提示无权限，409 表示用户名占用，422 表示输入格式错误，429 根据 `Retry-After` 等待。注册不能提交 `role`。用户名统一小写、不区分大小写。

密码以 Argon2id 哈希保存；随机会话令牌只保存 SHA-256 摘要。登录错误不会区分账号不存在和密码错误。按实际连接 IP 和用户名限制登录尝试；默认不采信客户端伪造的转发头。多用户代理部署时应由运维仅信任固定反向代理来源，避免所有用户共用代理 IP 限额。

## 管理员配置供应商

服务端提供 `/docs` 接口文档。先调用 `/v1/auth/login` 登录管理员，再在 **Authorize** 填写访问令牌即可调用管理员接口。普通用户访问一律 403。

| 方法和路径 | 用途 |
|---|---|
| `GET /v1/admin/providers` | 查看各供应商是否配置、模型 ID、API 地址；不返回 Key |
| `PUT /v1/admin/providers/qwen` | 保存百炼配置 |
| `PUT /v1/admin/providers/deepseek` | 保存 DeepSeek 配置 |
| `PUT /v1/admin/providers/amap` | 保存高德 Web Key |
| `POST /v1/admin/providers/{provider}/test` | 验证指定供应商，真实调用可能计费 |

百炼配置请求示意，尖括号内容由管理员替换：

```json
{
  "key": "<百炼API Key>",
  "base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1",
  "main_model": "<控制台可用的模型ID>",
  "lite_model": "<控制台可用的轻量模型ID>"
}
```

DeepSeek 同样使用 `key`、`main_model`、`base_url`，默认地址 `https://api.deepseek.com`；不传 `lite_model`。高德只传 `{"key":"<Web服务Key>"}`。Key 不含空白字符。API 地址仅允许对应供应商的官方 HTTPS 地址，不接受任意代理地址。

百炼 Key 和 API 地址必须属于同一地域；支持北京、新加坡及美国地域的标准兼容地址。工作空间专属域名暂未开放，避免任意地址造成服务端请求伪造。需要专属域名时应按官方域名规则单独扩展并验证。

LLM 测试传 `{}`，只测试路径中指定的供应商。高德测试需要传 `{"address":"明确的具体地点","city_adcode":"所在城市六位行政区划代码"}`，服务端不内置测试城市。供应商测试每种最多 10 次／15 分钟，供管理员诊断，不由用户每次规划触发。

保存成功只代表格式校验和加密存储成功；务必再测试账户权限及模型可用性。新配置用于后续请求，旧请求继续使用其开始时的配置。正常解析优先百炼、失败后尝试已配置的 DeepSeek；接口测试不会偷偷切换供应商。

## 配置、Git 与备份

环境变量仍可用于团队部署，数据库内通过管理员入口保存的配置优先于相应环境变量：

| 配置 | 说明 |
|---|---|
| `AMAP_WEB_KEY` | 后端高德 Web 服务 Key，现已放在本机 `server/.env` |
| `QWEN_KEY / QWEN_BASE / QWEN_MAIN / QWEN_LITE` | 百炼凭据与模型 |
| `DS_KEY / DS_BASE / DS_MAIN` | DeepSeek 凭据与模型 |
| `AUTH_REQUIRED` | 默认 1；临时兼容旧客户端时才使用 0 |
| `AUTH_ADMIN_USERNAME / AUTH_ADMIN_PASSWORD` | 可选，部署时初始化管理员；推荐终端命令隐藏输入密码 |
| `STATE_DIR` | 默认仓库根目录 `.state`；Docker 中为 `/srv/.state` 持久卷 |
| `PROVIDER_MASTER_KEY` | 可选，合法 Fernet 密钥；未配置时首次保存生成 `.state/provider.key` |
| `PARSE_USER_DAILY_MAX` | 每用户每日解析上限，默认 50 |
| `PARSE_LLM_DAILY_MAX` | 全局每日解析上限，默认 200 |
| `PARSE_LLM_TIMEOUT_S` | 单次解析模型调用上限，默认 10 秒 |
| `PARSE_TIMEOUT_S` | 包含重试及地图的整次解析上限，默认 20 秒 |

日额度按服务端 UTC 日期计数，用户名／用户 ID 以已校验的令牌为准。配置 0 表示禁止该类解析请求。配额失败时不生成计划。

`.env`、`.state/` 已被 Git 忽略。只提交代码、无密钥文档和锁定依赖；甲通过相同后端访问团队额度，无需持有供应商 Key。

同时备份 `auth.sqlite3`、`providers.sqlite3` 和 `provider.key`，或保管外部 `PROVIDER_MASTER_KEY`。数据库和加密密钥分开保管，限制运行账户之外的文件访问权限；Windows 文件权限继承自目录，需要部署人员设置受限 ACL。密钥丢失或不匹配时接口返回 503，禁止静默回退，恢复原密钥后再用。

生产依赖固定在 `server/requirements.lock` 并校验哈希；开发依赖在 `server/requirements-dev.lock`。Docker 单进程部署，账户、会话、额度和凭据落在持久卷；地图限流及模型熔断仍按进程维护。

参考：[百炼获取 API Key](https://help.aliyun.com/zh/model-studio/get-api-key/)、[DeepSeek API](https://api-docs.deepseek.com/)、[高德 Web 服务](https://lbs.amap.com/api/webservice/create-project-and-key)、[OWASP 密码存储](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。
